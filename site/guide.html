Install Nativol.

Download the DMG, drag Nativol to Applications, then complete the one-time setup.

Download Intel beta DMG

Release notes · SHA-256 checksum · Source & licenses

Writing currently requires a native Intel Mac on macOS 15.7.9 and macFUSE 5.4.0. This beta is ad-hoc signed and has not been notarized by Apple. Start with a spare drive and keep a separate verified backup. Apple Silicon work is paused.

1. Download and install

  1. Click Download Intel beta DMG above. Your browser downloads the installer disk image from GitHub; you may be asked where to save it.
  2. Compare the downloaded file with the linked SHA-256 checksum before opening it.
  3. Open Nativol-0.5.0-beta.1-Intel-Beta.dmg, usually in Downloads. Drag Nativol onto the Applications shortcut inside the disk image.
  4. Open Nativol from your Applications folder.

If macOS blocks the app because its developer cannot be verified, review Apple's instructions for opening an app you trust. After attempting to open it, the normal approval is in System Settings → Privacy & Security → Open Anyway. Review the app name and confirm only if you trust this download. Keep Gatekeeper enabled.

2. Install macFUSE 5.4.0

If this version is not already installed, get the official macFUSE 5.4.0 release. Open its disk image and run the macFUSE installer. Follow macFUSE's installation instructions, including the macOS extension approval and restart when requested. Return to Nativol afterward.

Nativol does not bundle or install macFUSE. This beta checks for version 5.4.0; another version is outside its supported writing configuration.

3. Set up background access

  1. In Nativol, select Setup, then Set Up Background Access…. Approve the macOS administrator prompt. Nativol reopens when setup finishes.
  2. In Setup, click Show NativolService to reveal the installed service, then Open Full Disk Access.
  3. In System Settings → Privacy & Security → Full Disk Access, use + to add the revealed NativolService, and switch it on. Approve macOS authentication if requested.
  4. Return to Nativol and check the status in Setup. If background access was already installed, the setup button is labelled Repair Background Access….

Administrator approval is for protected setup and updates. Ordinary drive operations use the background service without storing your password.

4. Turn on automatic writing

  1. In Setup, enable Automatically enable writing for external NTFS drives after reviewing the supported drive scope below.
  2. Enable Start in the menu bar when I sign in if you want Nativol to start after sign-in. If macOS asks, allow Nativol in System Settings → General → Login Items.
  3. Close the Nativol window to leave it running in the menu bar. Connect a backed-up spare NTFS drive and confirm Nativol reports writable access.

Automatic writing is off until you enable it. Once enabled, it applies to all eligible connected NTFS drives without per-drive enrollment. If a previous attempt failed before permissions were ready, use Enable Writing to retry, or safely eject and reconnect.

Supported drives

This beta accepts external physical NTFS drives over USB or Thunderbolt with a verified single-partition layout, supported 512/4096-byte geometry, and a successful read-only health check. Up to eight Nativol-managed volumes are supported.

Writing is refused when compatibility, identity, topology, health, or ownership cannot be established. Other filesystems remain managed by macOS. Nativol does not format or repair drives, force a busy unmount, or override a dirty or hibernated state.

Try your first transfer

  1. Copy a small folder of test files to the spare drive. Open them, copy them back, and compare their contents or checksums.
  2. Eject using Finder and wait for completion before unplugging. Reconnect, then repeat with Nativol's safe eject action.
  3. Restart and sign in. Check that the menu-bar app returns and reconnect the drive to confirm automatic writing.
  4. If Windows is available, read back the files there after a clean eject. File-content checks do not replace a filesystem integrity check.

Stop if copying, ejection, or identity checks fail. Leave the drive connected while safe eject is pending.

Get help or report results

Use GitHub Issues for installation help and non-sensitive test results. Include the app version, Intel Mac model family, macOS and macFUSE versions, connection type, approximate drive capacity, and exact error text with personal details removed.

Do not post full disk images, raw system logs, volume serials, home paths, personal filenames, or credentials. Report suspected privilege or integrity flaws through GitHub private vulnerability reporting.

Source & licenses

You do not need to download or build the source code to install Nativol. The optional matching source archive and source checksum are available for developers and reviewers.

The app's original code is MIT licensed. The NTFS engine, health checker, and patches retain their applicable GPL licenses, with corresponding source included. macFUSE is installed separately under its own license. Browse the public repository for notices and build instructions.

Broader hardware and lifecycle testing, a focused privilege-boundary review, and release signing/notarization remain before a production-readiness claim. Additional macOS versions and Apple Silicon require separate validation.
